# Support Policy

## Supported Code

- `main`: actively maintained.
- Tagged releases: best effort support for the latest release only.
- Older release tags: no guaranteed support.

## Getting Help

- Usage questions and bug reports: GitHub Issues.
- Feature requests: GitHub Issues.
- Security issues: use private vulnerability reporting as documented in [`SECURITY.md`](./SECURITY.md).

## Response Expectations

- New issue triage target: within 7 days.
- Security reports: follow the response targets in [`SECURITY.md`](./SECURITY.md).

## What Is Out of Scope

- Support for modified forks.
- Support for outdated Node, Rust, Solana CLI, or Anchor versions not documented in this repo.
